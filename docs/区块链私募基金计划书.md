# 一、基金概况

**无限数字资产私募基金一期**

|名称|内容|
|---|---|
|**基金名称**|无限数字资产私募基金一期|
|**基金类型**|数字资产投资基金（非公开合伙制）|
|**基金期限**|5年|
|**投资币种**|BTC、ETH、稳定币（USDT、USDC）、其他主流币质押项目|
|**初始规模**|10万美元 \(8万 \+ 2万\)|
|**认缴方式**|USDT/USDC 入金|
|**基金管理方（GP）**|CC、PP \(代号\)|
|**基金托管**|指定GP钱包以及交易所|

# 二、基金架构与角色

## 合约结构

- **普通合伙人（GP）**：基金管理人，负责投资、风险控制、资金管理、报告披露；

- **有限合伙人（LP）**：出资人，仅承担有限责任

## 投委会

- **人员组成:** 2 \~5 人组成 \(GP代表 \+ LP代表）

- **主要职责:** 批准投资策略调整、追加投资等

# 四、收益与退出机制

1. **基本原则**

    - 先回本，后分利

    - LP拥有优先回本权；

    - GP业绩提成在LP获得本金 \+ 约定收益后再计算。

2. **收益分配**

    |    名称|    内容|
    |---|---|
    |    **LP优先收益**|    年化 **x%** \(复利 或 单利\)|
    |    **超额收益分配**|    超过 **x%**  部分：LP **a%**，GP **\(100\-a\)%**|
    |    **~~管理费~~**|    ~~每年按实缴资产的 1\.5% 计提，用于运营成本~~|
    |    **~~业绩报酬~~**|    ~~基于高水位线原则（High\-water mark）计算~~|

**举例说明:**

> **假设复利年化8% \(超额收益分成GP:LP = 2:8\), 基金5年总收益率为100%，本金10万美元 → 总资产20万美元**。
> 
> 

- LP先取回本金\+优先收益约14\.7万美元 **\(公式: 10万美金 \* \(1\+0\.08\)^5\)**；

- 剩余利润5\.3万美元 → GP得20%（1\.06万），LP得4\.24万。

3. **本金亏损**

    - **共同承担:** 

        - 按照百分比共同随时

    - **GP裂后出资:**

        - LP优先回本、GP承担损失

# 五、退出与清算

- **正常退出 \- **基金自然结束

    - 卖出全部资产；

    - 以美元/稳定币清算；

    - 先返LP本金与优先收益，再按比例分配利润

- **提前退出 \- **中途赎回

    - 持有期满满1年后方可申请；

    - GP或其他LP有优先受让权；

    - 按月末净值（NAV）计算，折价5%\-10%退出

        - 举例说明:

            - 初始投资10万

            - 3年后NAV值为1\.4 总收益为: 10万 x 1\.4 = 14万

            - 假设折损10%, 退出LP拿走的钱为: 14万 x \(1\-10%\)=12\.6万

- **异常退出 \- **市场或政策原因

    - GP 与 LP表决后可提前终止基金

    - 本金亏损: 考虑亏损的情况

# 六、增资与新投资人机制

- 新投资人入场时按基金当前净值计算

- 原始LP享有优先增资权

- 举例说明:

    - 假设原始3年时间原始基金的10万美元已涨到13万美元

    - 新LP投资5万美金，按净值1\.3 \(13万/10万\)入场，买到 **38,462份额 **\(5万 ÷ 1\.3\)

    - 加入后总基金变成: 18万
