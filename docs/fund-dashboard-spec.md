# 区块链私募基金 — 资金看板与投资人报表 设计文档

> 版本：v0.5（分配参数全部确认，可进入开发）
> 基金：无限数字资产私募基金一期 ｜ 期限：5 年 ｜ 计价：USD（稳定币 USDT/USDC ≈ $1）
> 初始规模：100,000 USD（PP 80,000 + CC 20,000，均为 GP）｜ 认缴：USDT/USDC

---

## 1. 项目背景与目标

为「无限数字资产私募基金一期」搭建一个**本地运行**的资金看板 + 投资人报表系统。基金为非公开合伙制（GP/LP），5 年期，投资 BTC、ETH、稳定币及主流币质押。系统目标：

- 每日跟踪总资产、收益、单位净值（NAV）变化
- 持仓 / 成本 / 盈亏 / 质押收益
- **份额制记账**：按 LP/GP 分别记录出资、份额、单位净值
- 按收益分配瀑布计算 LP 优先收益、GP 超额提成
- 生成披露报表：日报（总资产/收益）、月报（NAV）、季度/半年度/年度投资人报表、单个 LP 对账单
- 支持增资（按当前净值折份额）与提前赎回（月末 NAV 折价）的测算
- 风控指标（资产集中度等）

**核心原则**：交易所 API Key 仅「只读」权限；系统只读取与计算，不下单、不划转。

## 3. 基金结构与份额制（核心模型）

### 3.1 角色

- **GP（普通合伙人）**：CC、PP。负责投资、风控、披露；享有超额收益提成。
- **LP（有限合伙人）**：出资人，有限责任；享优先回本权与优先收益。
- **投委会**：2~5 人（GP + LP 代表），批准策略调整、追加投资等（流程，非系统功能）。

### 3.2 单位净值与份额

- **单位净值（NAV/份）** = 基金当前总净值 ÷ 当前总份额。
- **初始**：100,000 USD，NAV/份 = 1.0000 → 总份额 100,000 份（80,000 + 20,000 按出资人拆分）。
- **申购 / 增资**：份额 = 出资额 ÷ 申购时 NAV/份（计划书例：3 年后净值 1.3，新 LP 投 5 万 → 5万 ÷ 1.3 = 38,462 份，总额变 18 万）。原 LP 享优先增资权（流程）。
- **赎回 / 退出**：份额按月末 NAV 折算，提前退出折价 **10%**（见 §4.9）。
- 每个投资人持有份额数 × 当前 NAV/份 = 其当前资产。

> 份额制是给多 LP 公平计收益的基础：不同时点申购的 LP，用同一 NAV/份折算，收益自然按份额公平分配。

## 4. 功能需求

### 4.1 每日资金变化折线图
X 轴日期，Y 轴可切换「总净值 USD」或「单位净值 NAV」。数据源：每日快照。可叠加累计盈亏、基准对比。

### 4.2 资产持仓列表
字段：资产、数量（含质押）、现价、市值、成本价、持仓成本、未实现盈亏、盈亏率、累计质押收益（数量/USD）、占比。
- 过滤：市值 < 1 USD 完全忽略。
- **集中度高亮**：单一资产占比 ≥ 50% 时标红预警（§4.10）。

### 4.3 成本价与盈亏
买入加权均价（手续费折 USD 计入）；无历史时手填并持久化、优先采用；质押所得按 0 成本（§7.3）。

### 4.4 质押收益
通过 OKX 账单接口（ccxt `fetch_ledger`）每日增量抓取，按 `billId` 去重累计；3 个月前用归档回填。质押属内部收益，**不计入现金流 / XIRR**，仅作收益归因展示。

### 4.5 单位净值与投资人份额（新增）
- 每日计算并存储 NAV/份 与总份额。
- 维护投资人台账（LP/GP、出资、份额、加入日期）。
- 每个投资人可查：持有份额、当前资产、累计出资、浮动收益。

### 4.6 整体年化（XIRR / TWR）
- 看板顶部：自起投 **XIRR**（资金加权，反映真实回报）。
- 报表期间业绩：**TWR**（时间加权，反映管理人业绩，剔除出入金时点影响）。
- 附注简单年化 / CAGR。

### 4.7 收益分配瀑布（核心，参数已确认）
按计划书「先回本、后分利」，逐出资人累计：

1. **返还本金**：优先返还各出资人本金（LP 优先于 GP carry）。
2. **优先收益**：年化 **8% 复利**，**按各出资人本金 + 各自持有期分别累计**：`本金 ×((1.08)^持有年数 − 1)`。
3. **超额收益分配**：超过「本金 + 优先收益」的剩余利润，按 **LP 80% / GP 20%** 分。
4. **GP 自有资金不抽 carry**：起投的 PP/CC 自有资金享受回本 + 8% 优先收益，但其超额部分**不扣 20%**（GP 不对自己抽成）；20% carry **只对未来外部 LP 的超额部分生效**。
5. **GP carry 池**在 PP 与 CC 之间**按出资比例 8:2 分**。
6. **无管理费、无单独高水位业绩报酬**（计划书已划除）。

> 计划书示例（嵌入校验）：本金 10 万、5 年总收益 100% → 20 万。取回 10万×1.08⁵≈14.69 万；剩余 5.31 万。若该本金为外部 LP：GP 20%（1.06 万）、LP 80%（4.25 万）；若为 GP 自有资金（如起投阶段）：不抽 carry，全归出资人。
> 样例演算（外部 LP 口径）：年均 25%、5 年末≈30.5 万，优先收益 14.69 万，剩余 15.81 万，GP 提成 3.16 万，LP 最终 27.34 万（回报率 173.3%）。

### 4.8 投资人报表（披露）
| 报表 | 周期 | 内容要点 |
| --- | --- | --- |
| 总资产 / 收益 | 每日 | 总净值、当日收益、累计收益（扣本金） |
| NAV 报告 | 每月 | 月末单位净值、当月涨跌 |
| 投资人定期报表 | 月度 / 季度 / 半年度 / 年度 | 期初/期末净值、期间 TWR、期间年化、净申赎、累计收益、自起投 XIRR、期末资产配置、期间质押收益、最大回撤、净值曲线 |
| LP 对账单 | 季度/年度（可选） | 该 LP 份额、出资、当前资产、按当前瀑布**测算**的应得本金+优先收益+超额分成 |

输出：看板内报表页（选周期查看）+ 导出 PDF/HTML 发投资人。报表按基金整体 + 可下钻到单个 LP。

### 4.9 赎回与退出测算
- 提前退出：**持有满 1 年**方可申请；按**月末 NAV** 计算，**折价 10%**；GP/其他 LP 有优先受让权（流程）。
  - 计划书例：3 年后 NAV 1.4 → 14 万，折 10% → 实退 12.6 万。
- 正常退出：5 年到期，卖出清算为稳定币，按瀑布分配。
- 系统提供「赎回测算器」：输入投资人 + 日期 + 折价率 → 输出可退金额与剩余份额。

### 4.10 风控指标
- **资产集中度 < 50%**：单一资产占比超阈值在持仓表与看板预警。
- 展示止盈/止损、调仓提醒为信息位（具体策略人工执行）；无杠杆（仅现货，天然满足）。

## 6. 数据存储（本地 Parquet）

每日快照幂等（同日覆盖）；账单按 `billId` 去重。

### 6.1 `snapshots`（1 行/天）
date(主键), total_value_usd, trading_value_usd, funding_value_usd, **total_units, nav_per_unit**, net_external_flow_usd（不含质押收益）, cumulative_inflow_usd, pnl_usd, created_at

### 6.2 `holdings`（多行/天）
date, asset, amount(含质押), price_usd, value_usd, cost_price_usd, cost_basis_usd, unrealized_pnl_usd, staking_amount, staking_value_usd, weight（占比，用于集中度）

### 6.3 `investors`（投资人台账）
investor_id(主键), name, role(GP/LP), join_date, gp_carry_weight(GP 在 carry 池中的权重), note
> 初始化两条：PP（role=GP，起投日出资 80,000，gp_carry_weight=0.8）、CC（role=GP，起投日出资 20,000，gp_carry_weight=0.2）。出资通过 §6.4 的申购记录体现。

### 6.4 `unit_transactions`（份额变动 = 申购/赎回，替代旧 cash_flows）
txn_id(主键), date, investor_id, type(subscribe/redeem), amount_usd, nav_per_unit, units_delta, discount(赎回折价), note
> 基金级现金流（XIRR 用）由本表派生：申购为负、赎回为正、末尾追加当前总净值。

### 6.5 `cost_overrides`（手动成本，持久）
asset(主键), cost_price_usd, note, updated_at

### 6.6 `staking_rewards`（质押收益流水，增量累计）
bill_id(主键去重), ts, asset, amount, bill_type, value_usd_at_receipt

### 6.7 `distribution_config`（分配参数，已确认）
pref_return_rate=0.08, compounding='compound'(复利), excess_lp_share=0.8, excess_gp_share=0.2, mgmt_fee=0, perf_fee=0, redeem_discount=0.10, gp_capital_carry=False(GP 自有资金不抽 carry), gp_carry_split={PP:0.8, CC:0.2}, pref_accrual='per_investor'(按各出资人本金+持有期累计)

### 6.8 `reports`（报表缓存，可选）
period_key(如 2026Q1/2026H1/2026FY/2026-03), period_start, period_end, nav_start, nav_end, navps_start, navps_end, net_flow, twr, period_pnl, cum_pnl, xirr_inception, max_drawdown, generated_at

## 7. 核心计算逻辑

- **7.1 估值**：总净值 = Σ(交易账户+资金账户 各币种×现价)，剔除 <1 USD；稳定币记 1。
- **7.2 加权成本**：买入 `新成本=(原量×原成本+买入额+手续费)/总量`；卖出按成本结转；手续费折 USD。
- **7.3 质押成本**：按 0 成本计入；持仓成本仅来自买入；未实现盈亏 = 市值 − 持仓成本。
- **7.4 单位净值**：`NAV/份 = 总净值 / 总份额`，每日存储。申购 `units=金额/当时NAV份`；赎回 `退款=份额×月末NAV份×(1−折价)`。
- **7.5 XIRR（自起投）**：`pyxirr.xirr(dates, amounts)`，质押收益不入现金流。
- **7.6 TWR（报表期间）**：按外部现金流分段，`r_k=V(流入前)/V(上段末)−1`，`TWR=∏(1+r_k)−1`；期间年化 `(1+TWR)^(365/天数)−1`。
- **7.7 分配瀑布**：本金 → LP 优先收益（复利 `本金×((1+r)^t−1)` 或单利 `本金×r×t`，按 LP 各自出资与持有期累计）→ 超额按 a%/(1−a%) 分。
- **7.8 最大回撤**：`max((历史峰值−当前)/历史峰值)`。
- **7.9 集中度**：`max(asset weight)`，≥50% 预警。

## 8. 技术架构

```
   OKX (REST via ccxt)
        │ 每日 UTC+8 00:00
        ▼
   collector.py — 余额(交易+资金)/行情/成交/出入金/账单(质押,billId去重) → 成本/盈亏/净值/NAV
        │ 幂等写入
        ▼
   Parquet: snapshots/holdings/investors/unit_transactions/cost_overrides/staking_rewards/distribution_config
        │ 读取派生
        ▼
   Streamlit 看板 + 报表
   · 日:总资产/收益/NAV折线/持仓(集中度预警)
   · 月:NAV报告  · 季/半/年:投资人报表(TWR/回撤/配置/瀑布)  · LP对账单
   · 赎回测算器  · 导出 PDF/HTML
```

选型：Python 3.10+ / ccxt / pandas+pyarrow(Parquet) / Streamlit(`st.data_editor` 改成本) / pyxirr / HTML 模板+WeasyPrint 转 PDF / cron(`CRON_TZ=Asia/Shanghai 0 0 * * *`) / .env + python-dotenv。
